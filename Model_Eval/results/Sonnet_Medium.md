- Каждая тема заканчивается мостом вперёд.
Проверенные факты (проверено 2026-10-29; источник — в скобках):
- Машина: представлена в апрельском номере BYTE за 1976 год, цена платы — 245 долларов; разработчик — сотрудник MOS Джон Мэй (Wikipedia «KIM-1»; вторичный источник, годится для справки, не для атрибуции в уроке). MCS6502 на 1 МГц от кварца 1 МГц (User Manual, Appendix A: «1 MHz XTAL»; драйвер MAME `kim1.cpp`: `1_MHz_XTAL`).
- Память: 1024 байта в восьми СОЗУ 6102 (1024 × 1 бит) + по 64 байта в двух 6530 = 1152 байта; брошюра заявляла «1 K BYTE RAM» (Wikipedia; арифметика сверена). ПЗУ монитора — 2048 байт в двух 6530: 6530-003 содержит 1024 байта по адресам $1800–$1BFF, 6530-002 — 1024 байта по $1C00–$1FFF (User Manual, раздел 3.2, Fig. 3-11…3-13; MAME `mem_map`). Номера 002 и 003 обозначают маску ПЗУ (pagetable.com, комментарии; Wikipedia «MOS Technology 6530»).
- Карта памяти (User Manual, раздел 3.2): $0000–$00FF — страница 0 (используемая часть $0000–$00EE, $00EF–$00FF занято монитором); $0100–$01FF — стек; $0200–$03FF — свободны для программ; $0400–$13FF — блоки K1–K4, декодируются под расширение 4К; $1700–$173F — ввод-вывод 6530-003 (таймер $1704–$170F); $1740–$177F — ввод-вывод 6530-002 (таблица памяти руководства, через поиск: «$1740–$177F I/O, timer of 6530-002»; в MAME: `0x1740–0x174f`); $1780–$17BF — 64 байта ОЗУ 6530-003; $17C0–$17EB — 44 байта ОЗУ 6530-002 для программ; $17EC–$17FF — ОЗУ 6530-002 для монитора. Декодируются только адреса A0–A12: в MAME все области имеют `mirror(0xe000)`, т. е. образ 8 КБ повторяется 8 раз (драйвер MAME `kim1.cpp`; аппаратно — декодер 74145 по A10–A12 даёт выбор «K0…K7», User Manual Appendix A, Chapter 6: K0 выбирает 1024 байта статического ОЗУ).
- Регистры 6530-003 по руководству: $1700 PAD (данные порта A), $1701 PADD, $1702 PBD, $1703 PBDD; у 6530-002 то же со смещением $40: $1740 SAD (данные сегментов), $1741 PADD, $1742 SBD (выбор разряда/ряда), $1743 PBDD (The First Book of KIM, листинги: `STA 1741` с `#$7F`, `STY SBD`; MAME `io_map`: смещения 0–3 с зеркалом 8).
- Таймер (User Manual, Appendix H; Hardware Manual §1.6.3.4): запись начального числа N по адресу ...04/05/06/07 задаёт делитель 1/8/64/1024 без разрешения прерывания, по ...0C/0D/0E/0F — с разрешением (прерывание выводится на PB7); счёт идёт до 256 интервалов; по достижении нуля устанавливается флаг, после чего счётчик уменьшается с частотой системного такта (делитель 1) вплоть до −255T; чтение или запись таймера сбрасывает флаг; чтение $1707 даёт состояние, бит 7 = «время вышло» (User Manual Appendix H). Модель MAME (`mos6530.cpp`): `timershift = {0, 3, 6, 10}` по A1A0; флаг устанавливается через `1 + N << shift` тактов после записи; чтение счётчика — по смещениям 4 и 6 (IE выкл.) и 12 и 14 (IE вкл.), чтение флагов — по смещениям 5, 7, 13, 15; бит 7 = таймер (`IRQ_TIMER = 0x80`), бит 6 — фронт PA7 (есть только у 6532 и в этих уроках не используется). Расхождение: Hardware Manual говорит о «флаге прерывания», User Manual — о «бите 7 состояния»; для эмулятора это одно и то же. В драйвере MAME KIM-1 линия прерывания 6530 к процессору не подключена: таймер опрашивают (`BIT $1707 / BPL`, The First Book of KIM, часы и «Black Match»).
- Порты 6530-002 (U2) на KIM-1 (драйвер MAME `kim1.cpp`; User Manual, Appendix I, комментарии монитора): PA0–PA6 — столбцы клавиатуры (активный уровень 0) и сегменты A–G индикатора; PA7 — вход приёма TTY; PB0 — выход TTY; PB1–PB4 — вход 74145, выходы 0–2 — строки клавиатуры, выход 4–9 — шесть разрядов индикатора; PB5 — разрешение записи на кассету; PB7 — вход кассеты (через PLL LM565 и компаратор 311). Значения `SBD`: $09, $0B, $0D, $0F, $11, $13 выбирают разряды (выход 74145 = SBD >> 1, бит 0 — линия TTY, остаётся 1) (The First Book of KIM: `LDA #$09 / STA 1742`, `LDY #$13 / STY SBD`; арифметика сверена кодом). Опрос строк клавиатуры — SBD = $01, $03, $05; $07 — строка 3 (переключатель TTY/KB в модели MAME).
- Индикатор и клавиатура: шесть семисегментных светодиодных индикаторов (4 — адрес, 2 — данные); клавиатура: 16 шестнадцатеричных цифр и AD, DA, +, PC, GO, RS, ST = 23 клавиши и переключатель SST (User Manual; MAME). Подпрограммы монитора: SCANDS $1F1F (показывает $00FB, $00FA, $00F9: POINTH, POINTL, INH), KEYIN $1F40, GETKEY $1F6A (возвращает код в A; $15 — нет нажатия), таблица сегментов `TABLE` $1FE7, OUTCH $1EA0, GETCH $1E5A (The First Book of KIM; для OUTCH/GETCH — cc65, kim1.sgml/ссылки; точное совпадение с ПЗУ проверять трассой, урок 06).
- Прерывания и векторы: RESET (кнопка RS), NMI (кнопка ST через таймер NE556; пошаговый режим SST — NMI по спаду SYNC, если выбран разряд K7 «не выполняется код монитора $1C00–$1FFF» — MAME `sync_w`); векторы NMIV $17FA/$17FB, RSTV $17FC/$17FD, IRQV $17FE/$17FF — в ОЗУ, младший байт первым; чтобы кнопка ST остановила программу и сохранила регистры, в $17FA/$17FB записывают $1C00 (User Manual Fig. 3-13). Сохранённые регистры монитора: $00EF PCL, $00F0 PCH, $00F1 P, $00F2 SP, $00F3 A, $00F4 Y, $00F5 X (там же). Аппаратные вектора 6502 лежат в $FFFA–$FFFF и из-за неполной дешифрации (A13–A15 не декодируются) читаются из $1FFA–$1FFF, то есть из ПЗУ 6530-002; их содержимое в уроках не приводится — снимается трассой.
- Телетайп: токовая петля 20 мА, полный дуплекс; скорость определяется монитором автоматически (DETCPS), в руководстве приведены 10, 15, 30 симв./с; запрос «KIM»; режим «только TTY» задаётся перемычкой A-21 — A-V (User Manual, разделы 2 и 3; Appendix C). PA7 — вход, PB0 — выход, PA0 читается как признак режима (Appendix I, комментарии). Аппаратное эхо: выход передатчика — И входа TTY и PB0 (MAME `tty_callback`).
- Кассета (User Manual, Appendix E и параметры раздела 4.2): запись начинается с 100 символов SYN ($16), затем `*` ($2A), ID записи, SAL, SAH, данные — каждый байт двумя ASCII-шестнадцатеричными символами, `/` ($2F), две контрольные суммы (CKL, CKH), два EOT ($04); каждый символ — 7 бит ASCII + бит чётности; каждый бит начинается тоном около 3700 Гц и заканчивается тоном около 2400 Гц (точнее 3623 и 2415 Гц, как 1/276 мкс и 1/414 мкс — арифметика сверена), «1» — переход тона на 1/3 длины бита, «0» — на 2/3; бит длится 3 × 2,484 мс = 7,452 мс (134,2 бит/с); запись «1» — 9 импульсов, «0» — 6 импульсов (Appendix E/Appendix I, комментарии; Wikipedia: 134,2 бит/с). Параметры сохранения: $17F5 SAL, $17F6 SAH, $17F7 EAL, $17F8 EAH, $17F9 ID (ID $00 и $FF при записи не использовать); запись — запуск с $1800, чтение — с $1873; десятичный режим сброшен записью $00 в $00F1 (User Manual §3.2/4.2; MAME-комментарий).
Расхождения и оговорки: число клавиш (23 против 24, см. выше); «3700/2400 Гц» — номинальные значения, фактические по длительности импульсов — 3623/2415 Гц; порядок разрядов индикатора (какой из 4…9 крайний слева) руководства в доступном тексте не приводят — определяется трассой урока 05; состояние некоторых строк OCR руководства неоднозначно (Appendix I), поэтому адреса подпрограмм, кроме SCANDS/KEYIN/GETKEY/TABLE (подтверждены двумя источниками), проверяются дизассемблированием.

### 01. KIM-1 как одноплатный компьютер.md

<!-- ПРИМЕЧАНИЕ:
Цель: что такое KIM-1 как «учебный» одноплатник: состав (6502, две 6530, ОЗУ 6102, индикатор, клавиатура, разъёмы TTY, кассеты и расширения), чем он отличается от Apple I, у которого есть терминал, но нет панели, и от Altair, у которого есть панель, но нет процессора на 6502; зачем KIM-1 в курсе.
Опора: М0.1.17.06 (история), М4.1.02 (состав Apple I), М4.3.03 (панель Altair).
Акценты: «компьютер без экрана»: 6 цифр, 23 клавиши и ПЗУ, которое умеет разговаривать с телетайпом; блок-схема платы: CPU + U2 (6530-002) + U3 (6530-003) + ОЗУ 6102 + 74145 + интерфейсы; три уровня общения с оператором — клавиатура/индикатор, телетайп, кассета.
Граница: история — М0.1.17.06; детали каждого блока — уроки 02–10; эмуляция — 11.
