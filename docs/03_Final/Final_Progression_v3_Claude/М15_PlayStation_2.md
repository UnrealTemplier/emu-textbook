> **Зачем:** Качественный скачок сложности: VLIW-векторные блоки с собственным микрокодом, шина к GS шириной 2560 бит, IOP как встроенный PS1-совместимый CPU.

#### М15.1 — Emotion Engine
- MIPS R5900 (128‑бит SIMD расширения) + VU0/VU1 (VLIW, собственный микрокод) + IPU (декодер MPEG2)

#### М15.2 — PlayStation 2 (2000) ✦
- EE + GS (Graphics Synthesizer: 2560‑бит шина к eDRAM, нет z-buffer читаемости) + SPU2 (48 голосов) + IOP (встроенный R3000A = PS1 compat)
- **Педагогика:** LLE невозможно без dynarec; демонстрация практического предела Go

---

### Д15а — Xbox Original (2001)
- Intel Pentium III «Coppermine» + NVIDIA NV2A GPU (DirectX 8); x86 в консоли — неожиданная архитектура

### Д15б — GameCube (2001), Wii (2006)
- IBM PowerPC Gekko/Broadway + кастомный Flipper/Hollywood GPU
- Wii = GameCube + расширения (MotionPlus, Wii Remote BT)

### Д15в — Nintendo DS (2004)
- ARM9 (главный) + ARM7 (звук/WiFi/совместимость GBA); двухэкранная архитектура

### Д15г — PSP (2004)
- MIPS R4000 (allegrex) + Media Engine; первая мощная портативная система
