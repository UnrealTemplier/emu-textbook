> **Зачем:** Первый ARM в курсе. ARM7TDMI — элегантная RISC ISA; Thumb — 16‑битное сжатие. GBA — отличная документация, небольшая система, мост перед MIPS/PS1.

#### М12.1 — ARM7TDMI (изолированный CPU)
- 32‑бит RISC, 16 регистров, barrel shifter, условные инструкции
- THUMB: 16‑битное подмножество
- Режимы процессора: User/FIQ/IRQ/SVC/ABT/UND

#### М12.2 — Game Boy Advance (2001) ✦
- ARM7TDMI + 2 PPU (BG + OBJ) + 4 DMA + 4 таймера + 2 прямых ЦАП
- Обратная совместимость с GB/GBC: дельта-режим
- **Тесты:** mgba-test-suite, gba-tests

> **Спутник М12 — Netlist-симуляция (введение):** Ознакомительный кейс: разбор транзисторной модели 6502 из проекта Visual6502. Реализация минимального netlist-симулятора на Go для понимания, как физический кристалл реализует ISA. Не заменяет основной эмулятор — дополняет понимание «real hardware» уровня.

### Д12а — Atari Jaguar (1993)
- «64‑битный» маркетинг: 5 процессоров (68000 + GPU RISC + DSP + видеочип + объектный процессор)
- Педагогика: как _не_ надо проектировать архитектуру

### Д12б — 3DO (1993)
- ARM60 + два видеочипа (CLIO + MADAM); раннее 3D без GPU

### Д12в — Virtual Boy (1995)
- 32‑бит NEC V810; стереоскопический векторный дисплей; коммерческий провал — поучительный кейс
