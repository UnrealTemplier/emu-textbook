> **Зачем:** x86‑64 в консолях, AMD GCN GPU, ARM SoC в Switch. Эмуляция доминируется JIT, GPU API трансляцией и HLE ОС. Финальный уровень курса: граница между эмуляцией и виртуализацией.

#### М17.1 — Sony PlayStation 4 (2013) ✦
- AMD Jaguar x86‑64 × 8 + AMD GCN (Radeon RX) + FreeBSD‑based Orbis OS
- GPU командный буфер, IB (Indirect Buffer), эмуляция GNM API поверх Vulkan
- Shadps4 / RPCS4 как эталоны

#### М17.2 — Nintendo Switch (2017) ✦
- ARM Cortex‑A57 × 4 + Nvidia Maxwell GPU (Tegra X1) + Horizon OS
- JIT: ARM → ARM + Vulkan API трансляция (Ryujinx как эталон)

---

### Д17а — Xbox One (2013)
- AMD Jaguar × 8 + AMD GCN + ESRAM + Hyper‑V гипервизор

### Д17б — PlayStation 5 (2020), Xbox Series X/S (2020)
- Zen 2 + RDNA 2; обратная совместимость через ускоренную x86‑64 эмуляцию

### Д17в — Nintendo Switch 2 (2025)
- ARM Cortex‑X2 + Nvidia Ampere GPU; Ray Tracing в мобильной консоли
