### 04. Целочисленная арифметика и битовые операции в Rust.md

<!-- ПРИМЕЧАНИЕ:
Цель: как Rust обращается с переполнением и сдвигами: проверки в отладочной сборке, явные методы `wrapping_*`, `checked_*`, `overflowing_*`, `saturating_*`, тип `Wrapping<T>`, `rotate_left`/`rotate_right`, `count_ones`, `from_le_bytes`/`to_be_bytes`, преобразования `as` и `From`/`TryFrom`.
Опора: М0.9.11, М0.9.13 (UB в C), М0.11.06 (определённое поведение в Go).
Акценты: `overflowing_add` сразу возвращает результат и признак переполнения — удобно для флагов CPU; в эмуляторах на Rust арифметику регистров пишут через `wrapping_*`, иначе отладочная сборка падает на нормальном для гостевой машины переполнении.
Проверенные факты: по The Rust Reference, переполнение целочисленных операторов (`+`, `-`, `*`, а также сдвиг на величину не меньше ширины типа) в отладочной сборке вызывает панику, управляется флагами `-C debug-assertions` и `-C overflow-checks`; деление самого отрицательного значения на −1 проверяется всегда; по The Rust Programming Language (гл. 3.2), в release-сборке без проверок переполнение оборачивается по правилам дополнительного кода.
Иллюстрации: реального объекта у урока нет: собственная схема — таблица «операция → поведение в debug и release → методы `wrapping_*`, `checked_*`, `overflowing_*`, `saturating_*`» (Markdown); примеры побитно.
-->
