> **Зачем:** Студент самостоятельно выбирает систему за пределами пройденного курса и реализует её эмулятор с нуля, применяя весь накопленный арсенал.

#### Требования Capstone
- Выбор системы + обоснование педагогической ценности
- ADR-документ архитектурных решений (по шаблону, введённому в М4)
- Полный цикл: реверс‑инжиниринг → тест-ROM (с помощью ассемблера из М3) → реализация → регрессии
- Сравнение трейсов с эталонным эмулятором (через дифференциальный трейсер из М3)
- Инженерный дневник разработки (ведётся с М4)
- Открытая публикация: GitHub, лицензия MIT, homebrew ROM для демо, опционально WASM-версия (навык из М10)
