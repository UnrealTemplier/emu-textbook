> **Зачем:** Первый 64‑битный курсовой проект. RSP с микрокодом (VLIW DSP) — качественный скачок сложности; RDP — полноэкранный растеризатор с Z-буфером.

#### М14.1 — MIPS VR4300 (64‑битный MIPS)
- 64‑бит MIPS III ISA; FPU встроена (COP1); вся арифметика 64‑бит

#### М14.2 — Nintendo 64 (1996) ✦
- VR4300 + RSP (VLIW DSP, микрокод ucode) + RDP (растеризатор с Z-буфером, текстурирование, AA) + AI (аудио) + VI (видео интерфейс)
- Микрокод как HLE (высокоуровневая эмуляция RSP через перехват F3D/F3DEX)
- **Тесты:** n64-tests, ultralib behavioral tests

---

### Д14а — Sega Saturn (1994)
- Двойной SH‑2 + SCU DMA + VDP1 (quad‑based рендер) + VDP2 (фоновые слои) + SCSP (звук)
- Кошмар синхронизации двух CPU; VDP1 с четырёхугольниками вместо треугольников

### Д14б — Sega Dreamcast (1998)
- SH‑4 (суперскалярный) + PowerVR2 (тайловый отложенный рендеринг) + AICA (звук)
- PVR2: принципиально иная архитектура GPU — первое знакомство с тайловым рендерингом
