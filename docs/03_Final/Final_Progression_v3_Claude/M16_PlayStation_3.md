> **Зачем:** Cell BE — гетерогенная многоядерная архитектура. Один из самых сложных объектов для эмуляции в истории. Без dynarec и GPU API трансляции — невозможно.

#### М16.1 — Cell Broadband Engine
- 1 PPE (PowerPC) + 8 SPE (SIMD, локальная SRAM 256 КБ) + EIB (кольцевой интерконнект)
- DMA между PPE и SPE через EIB

#### М16.2 — PlayStation 3 (2006) ✦
- Cell BE + RSX (NVIDIA G70, не документирован) + Audio: Cell DSP + XDR DRAM
- RPCS3 как эталонный эмулятор: изучение архитектуры через исходники

---

### Д16а — Xbox 360 (2005)
- Xenon: 3 ядра PowerPC / 6 HW-потоков + Xenos (ATI R500 с EDRAM)
- Равномерно сложен с PS3; интересен единым шейдерным процессором (unified shaders)

### Д16б — Wii U (2012)
- IBM PowerPC Espresso + AMD Radeon-based GPU; прямой потомок GameCube/Wii (обратная совместимость)

### Д16в — Nintendo 3DS (2011), PlayStation Vita (2011)
- 3DS: ARM11 MPCore (2+1 ядра) + кастомный PICA200 GPU
- Vita: ARM Cortex‑A9 × 4 + SGX543MP4; отличная документация (HENkaku)
