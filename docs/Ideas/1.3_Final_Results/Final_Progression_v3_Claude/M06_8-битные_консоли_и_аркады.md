> **Зачем:** Первое столкновение с PPU, тайловой графикой, спрайтами и APU. Документация отличная — идеально для изучения полной игровой системы.

#### М6.1 — Game Boy (DMG, 1989) ✦ _(идеальный учебный консольный проект)_
- LR35902 (Z80‑совместимый) + LCD-контроллер + простой DMA + Game Link
- Единое адресное пространство CPU и видео; нет сложных мапперов в базе
- **Тесты:** Mooneye-GB, SameBoy, blargg, Wilbertpol

#### М6.2 — NES / Famicom (1983) ✦ _(ключевая система для PPU/APU)_
- Ricoh 2A03 (6502 без BCD + APU) + PPU 2C02 (отдельная шина VRAM/OAM) + мапперы MMC1/MMC3
- Sprite‑0 hit, scroll-splitting, DMA OAM
- **Тесты:** nestest, blargg cpu/ppu, nes-test-roms

> **Спутник М6 — TUI-отладчик:** На базе Bubble Tea реализуется TUI-отладчик: дизассемблер, пошаговое выполнение, брейкпоинты по адресу и условию, дамп памяти, дамп регистров в реальном времени. Используется для NES/GB и всех последующих систем.

> **Спутник М6 — Savestates и Rewind:** Механизм сохранения/восстановления полного состояния эмулятора (savestate) реализуется на NES как первом достаточно полном объекте. Основа детерминизма: один поток, нет глобального состояния.

---

### Д6а — Sega SG‑1000 (1983), ColecoVision (1982)
- Z80 + TMS9918 VDP: первое знакомство с тайловым движком без сложностей

### Д6б — Sega Master System (1985)
- Z80 + VDP (эволюция TMS9918) + FM‑звук (YM2413 в японской версии)

### Д6в — Pac‑Man (аркада, 1980)
- Z80 + кастомная видеосхема; Ghost AI как поведенческая эмуляция

### Д6г — Atari 5200 (1982), Atari 7800 (1986)
- 6502-семейство; 7800 имеет обратную совместимость с 2600 — демонстрация дельта-подхода
