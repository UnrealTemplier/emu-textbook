> **Зачем:** CPU + видео + звук + I/O + хранение данных. Первое столкновение с реальной периферией и её нестандартным поведением.

#### М5.1 — Apple II (1977) ✦
- MOS 6502 + soft switches, NTSC-артефакты, Disk II (GCR-автомат)
- Слоты расширения как шинная архитектура
- **Тесты:** A2 diagnostics ROMs

#### М5.2 — ZX Spectrum (1982) ✦
- Z80 + ULA: contention (конфликты шины CPU и видео), border-эффекты
- Атрибутный цветовой режим: colour clash как аппаратное ограничение
- **Тесты:** FUSE CPU tests, spectaculator tests

#### М5.3 — Commodore 64 (1982) ✦ _(самая сложная 8‑битная машина курса)_
- 6510 (6502 + I/O-порт) + VIC‑II (badlines, raster IRQ, спрайты) + SID (синтез звука) + CIA 6526
- 1541 как отдельный микрокомпьютер (6502 + GCR-декодер)
- **Тесты:** VICE test suites, SIDtest

> **Спутник М5 — Вывод видеобуфера через Ebitengine/SDL2:** Подключается минимальная графическая оболочка только для вывода готового фреймбуфера. Ядро эмулятора остаётся headless; библиотека — только на границе вывода. Звуковой буфер — горутины для очереди (единственный легитимный случай).

---

### Д5а — VIC‑20 (1980)
- Предшественник C64; VIC чип проще VIC‑II — хороший трамплин перед C64

### Д5б — BBC Micro (1981)
- 6502 + телетекстовый видеочип + встроенный ассемблер BBC BASIC

### Д5в — Atari 400/800 (1979)
- 6502 + POKEY (звук + клавиатура) + GTIA/ANTIC (DMA-ориентированный видеорежим)

### Д5г — MSX (1983)
- Z80 + TMS9918 (VDP) + AY‑3‑8910; стандартизованная платформа

> _(между М5 и М6)_

- IRQ, NMI: аппаратные прерывания, маскирование, вектора
- Контроллер прерываний: приоритеты, вложенность (Intel 8259 PIC)
- RESET, NMI, IRQ в 6502 — точная семантика с латентностью
- Polling vs. interrupt-driven I/O
- **Практика:** добавить таймер с IRQ в Apple II эмулятор (прерывания Space Invaders — RST 1 и RST 2 процессора 8080, у которого нет NMI, — уже реализованы в М4.2.05)
