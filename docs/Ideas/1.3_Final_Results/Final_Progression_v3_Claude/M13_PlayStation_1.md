> **Зачем:** Первый большой 3D-проект курса. MIPS — чистая RISC ISA; GTE — геометрический сопроцессор; GPU без Z-буфера — принципиально иная растеризация.

#### М13.1 — MIPS R3000A (изолированный CPU)
- 32‑бит RISC, 32 регистра, load delay slots, branch delay slots
- Coprocessor interface: COP0 (системный), COP2 (GTE)

#### М13.2 — Sony PlayStation 1 / PSX (1994) ✦
- R3000A + GTE COP2 (матрицы, векторы, перспектива) + GPU (GP0/GP1, нет Z-буфера) + SPU (24 голоса PCM + реверберация) + CD‑ROM
- DMA для GPU/SPU/MDEC, BIOS (LLE vs. HLE)
- **Тесты:** amidog CPU/GTE tests, psx-spx (nocash specs)

### Д13а — Sega 32X (1994)
- Аддон к Mega Drive: двойной SH‑2; демонстрация многопроцессорной синхронизации дёшево

### Д13б — Sega CD (1991)
- CD‑ROM субсистема к Mega Drive: 68000 + CD‑DSP; формат BIN/CUE, mixed‑mode CD
