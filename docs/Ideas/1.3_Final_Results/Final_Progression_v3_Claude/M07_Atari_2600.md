> **Зачем:** «Racing the beam» — нет кадрового буфера; картинка формируется прямо во время обхода луча. Эмулятор обязан быть cycle‑accurate с первой строки. Намеренно помещён _после_ NES/GB — как предупреждение, а не старт.

#### М7.1 — Atari 2600 / VCS (1977) ✦
- 6507 (6502 без NMI/IRQ и с урезанной шиной) + TIA (Television Interface Adaptor): 128 байт RAM, 0 фреймбуфера
- Wsync, HMOVE, RESP0/1, Playfield — всё вручную в CPU
- **Книга:** _Racing the Beam_ (Montfort & Bogost) — обязательна
- **Тесты:** Stella test ROMs, atari2600-test-roms

> **Спутник М7 — «Сломанный эмулятор» (Broken Emulator):** Первый полноценный кейс: студент получает Atari 2600 эмулятор, проходящий 90% тестов. Задача — локализовать баги в TIA, выдвинуть гипотезы, написать регрессионные тесты и починить. Формат применяется далее в каждом сложном модуле.

### Д7а — Vectrex (1982)
- 6809 + аналоговый векторный дисплей (не растровый); уникальная система без пикселей

### Д7б — Atari Lynx (1989)
- 65C02 + Mikey (звук + DMA) + Suzy (спрайтовый движок с масштабированием)

> _(между М7 и М8)_

- Процессорное копирование (CPU loop) → выделенный DMA-контроллер
- Конкуренция CPU и DMA за шину: steal cycles
- DMA в NES (OAM DMA), в Mega Drive (VDP DMA), в PS1 (MDEC/SPU DMA)
- Intel 8237 DMA Controller (появится в x86 PC)
- **Практика:** реализовать OAM DMA в NES с корректным steal‑cycles; покрыть blargg DMA-тестами
