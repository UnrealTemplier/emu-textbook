> **Зачем:** Моторола 68000 — образцовая ортогональная CISC ISA; Mega Drive — первый «взрослый» двухпроцессорный проект с VDP и FM‑синтезом.

#### М9.1 — Motorola 68000 (1979) ✦ _(изолированный CPU)_
- 16/32‑бит, 8 регистров данных + 8 адресных, ортогональная ISA
- Exception processing: векторная таблица, supervisor/user mode
- **Тесты:** 68000 CPU test suite (Testall)

#### М9.2 — Sega Mega Drive / Genesis (1988) ✦ _(первая двухпроцессорная система)_
- 68000 (главный) + Z80 (звуковой субпроцессор) + VDP (скроллинг, DMA, спрайты) + YM2612 (FM) + SN76489 (PSG)
- Арбитраж шины между CPU и DMA/VDP
- **Тесты:** Exodus test suite, md-test-roms

---

### Д9а — Amiga 1000 / 500 (1985)
- 68000 + три кастомных чипа: Agnus (DMA/Copper/Blitter), Paula (звук/диск), Denise (видео)
- Copper-программирование: процессор разметки экрана без CPU
- Blitter: аппаратный блит/копировщик с AND/OR/XOR логикой

### Д9б — Atari ST (1985)
- 68000 + Yamaha YM2149 + GLUE-чип; проще Amiga — хорошее введение в 68000-машины

### Д9в — Sharp X68000 (1987)
- 68000 + кастомная японская видеосистема; редкий кейс экзотической платформы

### Д9г — Apple IIGS (1986)
- 65C816 (16‑битный 6502) + Ensoniq ES5503 (цифровой синтез); мост 6502 → 65816 → SNES
