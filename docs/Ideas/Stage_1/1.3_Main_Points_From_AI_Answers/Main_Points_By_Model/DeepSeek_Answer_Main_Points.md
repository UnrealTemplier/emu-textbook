# Конспект ответа DeepSeek

## 1. Концепция и глобальное позиционирование
- **Трактовка проекта:** Мета-проект и долгосрочный инженерный тренажер на 10–15 лет. Эмуляторостроение рассматривается не как заучивание алгоритмов, а как моделирование полного инженерного цикла: выбор тулинга, чтение спецификаций, формулирование сомнений, проектирование архитектуры, написание тестов, отладка и рефакторинг.
- **Главный риск:** Бесконтрольное разрастание (расползание масштаба), когда 5000 страниц рискуют превратиться в 50 000. 
- **Средство борьбы с риском:** Введение жесткого унифицированного шаблона урока, единого глоссария, карты зависимостей модулей и строгой архитектурной преемственности кода между главами.

## 2. Хронологический охват и расширение списка систем
DeepSeek систематизирует около 60 систем по хронологическим эпохам:
- **До 1970:** Машина фон Неймана (1945), Manchester Baby (1948), EDSAC (1949), UNIVAC I (1951), IBM 701/650/704, IBM 709 (1957), IBM 7090 (1958), IBM 1401, DEC PDP-1, IBM 7094, PDP-4/PDP-7, IBM System/360, CDC 6600, PDP-8 (1965), HP 2116, DG Nova, PDP-11 (1970).
- **1970-е:** Intel 4004, Kenbak-1, 8008, 8080, 6800, Altair 8800, MOS 6502, Z80, Apple I, TMS9900, Apple II, Commodore PET, TRS-80, Atari 2600, 8086, 68000, 8088, Atari 400/800, TI-99/4A.
- **1980-е:** VIC-20, Sinclair ZX80/ZX81, IBM PC (1981), BBC Micro, C64, ZX Spectrum, 80186, 286, NES/Famicom (1983), SG-1000, MSX, Apple Lisa, Macintosh (1984), Amiga, Atari ST, 386, SMS, Mega Drive (1988), Game Boy (1989), 486, Atari Lynx.
- **1990-е:** SNES (1990), Neo Geo, Game Gear, 3DO, Jaguar, Pentium (1993), PlayStation (1994), Saturn (1994), Virtual Boy, N64 (1996), Dreamcast (1998).
- **2000-е – 2010-е:** PS2, GameCube, Xbox, GBA, NDS, PSP, Xbox 360, PS3, Wii, 3DS, PS Vita, Wii U, PS4, Xbox One, Nintendo Switch, PS5, Xbox Series X/S.

## 3. Лестница педагогической сложности
- **Уровень −1 (Подготовка):** Машина фон Неймана, игрушечный 8-битный процессор на 16 команд, CHIP-8 (базовые приемы эмуляции памяти, флагов, регистров, дисплея).
- **Уровень 0 (Простейшие CPU как изолированные ядра):** Intel 4004, PDP-8, MOS 6502, Intel 8080 / Z80, Motorola 6800, Intel 8008.
- **Уровень 1 (Простые полные системы):** Atari 2600, NES/Famicom, Sega Master System, Game Boy, Apple I, Altair 8800, Commodore PET, VIC-20.
- **Уровень 2 (Средние системы):** Apple II, Commodore 64, ZX Spectrum, BBC Micro, IBM PC/XT, 80286, Mega Drive, SNES, Amiga, Atari ST, Macintosh, Neo Geo.
- **Уровень 3 (Сложные системы):** Intel 386/486, PS1, N64, Saturn, Dreamcast, PS2, GameCube, Xbox, PSP, Nintendo DS.
- **Уровень 4 (Экстремально сложные системы):** Xbox 360, PS3, PS4, Xbox One, Switch, консоли 9-го поколения.
- *Оговорка по мейнфреймам (IBM 709/7090, PDP-7, PDP-11):* Эмуляция ядра CPU относится к уровню 1–2, но полноценная эмуляция систем с каналами ввода-вывода, лентами и ОС относится к уровню 3–4.

## 4. Инженерный анализ и рекомендации
- **Сквозной унифицированный фреймворк на Go:** Не писать каждую систему в изолированном стиле, а с первых уроков развивать общие базовые типы: `Bus`, `CPU`, `Clock`, `Device`, `Debugger`, `TestHarness`.
- **Двухэтапная модель урока в каждом модуле:**
  1. *CPU Core level:* реализация изолированного процессора.
  2. *Full Machine level:* шина, тайминги, видео, контроллеры и периферия. Это позволяет завершить модуль на этапе CPU, если машина целиком слишком сложна.
- **Встроенные инструменты разработки:** Отладчик (дизассемблер, пошаговое выполнение, брейкпоинты, дамп памяти) создается в самом начале курса и развивается вместе с эмуляторами.
- **Тестовая культура (Test-Driven Development):** Интеграция эталонных тестовых пакетов в каждый модуль:
  - 6502 / NES: `nestest`, тесты Клауса Дорманна (Klaus Dormann), Tom Harte tests, blargg.
  - Game Boy: Mooneye, SameBoy, blargg.
  - Mega Drive: Exodus tests; PS1: amidog tests.
- **HLE против LLE:** Обязательное теоретическое и практическое разделение низкоуровневой эмуляции чипов и высокоуровневой эмуляции системных вызовов/BIOS (критично для поздних платформ).
- **Роль языка Go:**
  - *Идеален для:* интерпретаторов, шин, отладочных утилит, сборки эмулятора в WASM для работы прямо в браузере, юнит-тестирования.
  - *Ограничения:* JIT-компиляция / динамическая рекомпиляция (сложно взаимодействовать с рантаймом Go), отсутствие ручного управления памятью, сборщик мусора в критических горячих циклах. Для PS2/PS3/Xbox 360 интерпретатор на Go непригоден по производительности.
- **Юридическая безопасность:** Использование только homebrew, тестовых ROM и PD-контента; запрет на распространение проприетарных BIOS в рамках учебника.
- **Расширенный шаблон урока (10 шагов):**
  1. Цели урока → 2. Пререквизиты → 3. Теория → 4. Источники и документация → 5. Проектирование (альтернативы и компромиссы) → 6. Практика (пошаговая реализация) → 7. Тесты → 8. Упражнения → 9. Рефлексия и разбор ошибок → 10. Что дальше.
  - Специфические вставки: «Инженерный дневник», «ADR», «Скользкое место», «Как это сделано в MAME / higan / ares / Dolphin».
- **Рекомендуемый MVP-маршрут:** Основы + Go → Машина фон Неймана → CHIP-8 → Intel 4004 → MOS 6502 + NES → Game Boy → 68000 + Mega Drive → PlayStation 1.
