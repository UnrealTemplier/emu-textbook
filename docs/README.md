# Документация проекта

Карта папок `docs/`. Каждая папка относится к одной стадии работы или к архиву.

```
docs/
├── 00_Project/                  описание проекта (частично устарело, см. «Статус»)
├── 01_Idea/                     этап 1: исходная идея и сырые ответы ИИ
│   ├── 01_Initial_Prompt/       исходный промпт и основные тезисы
│   └── 02_AI_Answers/           ответы моделей и конспекты (Summaries/)
├── 02_Working/                  этап 2: справочные и рабочие материалы
├── 03_Final/                    этап 3: текущие версии учебника
│   └── Final_Progression_v3_Claude/   общая часть (00) и файлы модулей М00–М18
└── 99_Archive/                  закрытое и устаревшее, ничего не удалено
    ├── Progression_v1_v2_v3/    старые версии прогрессии
    ├── Project_Points_v1/       первая версия описания проекта
    ├── Revision_v2_to_v3/       промпты, черновики и ревизии перехода v2 → v3
    ├── Working_Stage2/          выжимка понравившихся идей и варианты прогрессий (заменены прогрессией v3)
    └── Engine_Images_Task/      задание на поддержку изображений в движке и книге (выполнено)
```

## Статус

- Актуально: `00_Project/`, `03_Final/`.
- Рабочее: `02_Working/` — `Prompt_Expand_Subsection.md` (промпт для расширения и детализации подразделов прогрессии), `Prompt_Rework_Module.md` (промпт для переработки модулей М5–М18 в новый формат), `Plan_Expand_М0.1_History.md` и `Prompt_Expand_М0.1_History.md` (утверждённый план расширения М0.1 и пошаговый промпт с очередью и журналом: в новом чате подключить промпт и написать «Продолжай дальше»), `Chronological_Systems_List.md` (справочный хронологический список систем).
- Историческое: `01_Idea/` (сырьё, на основе которого строилась прогрессия), `99_Archive/`.

> **Оговорка.** `00_Project/Project_Points_v2.md` составлен по старой прогрессии: в нём ещё есть факультативные ветки Д, блоки LAB/MODULE и шаблон модуля из 7 глав. Документ будет исправлен после завершения работы над прогрессией. До тех пор при расхождении действует прогрессия в `03_Final/`.

## Именование

- Папки этапов: `NN_Название`, без точек, пробелов и стрелок.
- Номера модулей двузначные: `М00`…`М18`. Буква «М» в обозначениях модулей — всегда кириллическая, в именах файлов и в тексте.
- Версии указываются в именах архивных файлов. Текущий файл без номера версии. Исключение: `Final_Progression_v3_Claude/` сохраняет имя, на которое ссылается `00_Общая_часть.md`.
- Авторство ревизий указано в имени: `Review_Gemini`, `Review_ChatGPT`, `Review_Claude`.
