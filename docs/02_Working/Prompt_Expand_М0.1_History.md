# Промпт: расширение М0.1 «История вычислительной техники» — пошаговая работа

**Как пользоваться.** В новом пустом чате подключить этот файл (`@docs/02_Working/Prompt_Expand_М0.1_History.md`) и написать «Продолжай дальше». Агент сам определяет по журналу (раздел 7), какой шаг следующий, выполняет **ровно один шаг** очереди (раздел 6), коммитит, записывает итог в журнал и останавливается с отчётом. Контекста прежних чатов у агента нет: всё нужное — в этом файле и в файлах, на которые он ссылается.

## 4. Как выполнять шаг «папка NN»

Общий порядок — разделы 1–9 `Prompt_Expand_Subsection.md`. Особенности М0.1:

Если проверка фактов требует переставить справки по хронологии, это допустимо. Перестановку нужно записать в «Исправлено относительно прежней версии» примечания папки и обновить номера в плане (разделы 3, 5, 7.2).
2. **Примечание папки** (`### NN. Название/`) — поля: Цель, Плоскость, Опора, Граница, Вперёд, Структура (группы уроков по номерам), Сквозная линия эпохи (какие линии раздела 3 плана проходят через папку, с номерами уроков), Исправлено относительно прежней версии (было/стало, таблица «прежний номер → новый», какие упоминания стали уроками, что ссылки обновлены), Для генерации.
3. **Примечание каждого урока** — поля по разделу 4 `Prompt_Expand_Subsection.md`: Цель, Опора, Акценты, Граница, Вперёд, Практика (с ответами, проверенными перед записью), Для генерации (если есть особенности), Иллюстрации, Термины, Проверенные факты. Справкам о системах из модулей М1–М18 — «Где встречается дальше в учебнике» с номерами подразделов.
4. **Упоминания** (второстепенные системы и люди) — в уроках «Вычислительные устройства и предтечи» и «Люди эпохи»: одна-две фразы с проверенной датой. Упоминание, ставшее уроком, остаётся строкой со ссылкой на урок.
5. **Факты** — каждую дату, число, атрибуцию проверять в вебе сразу, до записи. Источники по эпохам — раздел 2.6 плана. Независимые поиски запускать параллельно. WebSearch и WebFetch — отложенные инструменты: перед первым вызовом загрузить их через ToolSearch (`select:WebSearch,WebFetch`). Мифы и спорные приоритеты помечать явно, отделяя факт, реконструкцию и гипотезу. Писать «по памяти» или «сверить позже» нельзя.
6. **Иллюстрации** — у каждого урока. Файлы Commons проверять через API пакетами:
   - поиск: `https://commons.wikimedia.org/w/api.php?action=query&list=search&srnamespace=6&srsearch=…&format=json`;
   - лицензия: `action=query&prop=imageinfo&iiprop=extmetadata&titles=File:…|File:…&format=json`, поля `Artist` и `LicenseShortName`.

   Разрешены PD, CC0, CC BY, CC BY-SA и открытые лицензии из `[media] allowed_licenses` в `book.toml` (OGL, OGL-C, Licence Ouverte, dl-de, FAL); полный список и запреты — раздел «Иллюстрации» `00_Общая_часть.md`. Портреты хранятся в уроке-биографии М0.1.25, в других уроках — «встроить из М0.1.25.NNN». Фото машины хранится в её справке.
7. **Новые биографии своей папки** (раздел 6.1 плана) — вставить в `25_Великие_люди_эпох.md` по проверенному году рождения, сразу в полном формате. Секции: Жизнь и эпоха; Идеи, задачи и методы работы; Конфликты и ограничения; Влияние работ и судьба идей; Признание, забвение и историческое наследие; Главные даты; Мифы и спорные атрибуции; Где встречается в учебнике. Примечание — со всеми полями, включая «Эпоха: М0.1.NN …». Затем:
   - перенумеровать трёхзначные номера всех биографий после вставки;
   - найти и обновить точные ссылки `М0.1.25.NNN` во всём `docs/03_Final/` (`grep -rnoP 'М0\.1\.25\.\d{3}'`);
   - дописать человека в «Биографии в М0.1.25: …» примечания урока «Люди эпохи» своей папки.
8. **Сквозные правки:**
   - ссылки на прежние номера уроков своей папки во всём `docs/03_Final/` перенумеровать скриптом по таблице «прежний → новый». Список известных ссылок — раздел 7.1 плана, но искать всё равно grep-ом: `grep -rnoP 'М0\.1\.NN\.\d\d(?!\d)'`;

9. **Проверки** — временный скрипт в scratchpad, в репозиторий его не класть:
   - все прежние пункты `- ` и названия уроков папки (`git show HEAD:<файл>`) есть в новом файле;
   - комментарии `<!--` и `-->` парные во всех изменённых файлах;
   - нумерация уроков сквозная, с `01`, без пропусков, и совпадает с таблицей плана;

   - названные файлы Commons существуют, их лицензии разрешены (API);

## 8. Начало и конец каждого чата

**В начале:**
1. Прочитать этот файл целиком.
2. `git -c core.quotepath=off status --short` и `git log --oneline -5`.
3. Сверить состояние с журналом:
   - последний `[x]` в очереди должен совпадать с последним коммитом `docs: expand М0.1…`;
   - незакоммиченные изменения должны быть описаны в журнале как промежуточное состояние (кроме локальной правки автора из записи шага 0).

   Если не сходится — не продолжать, а описать расхождение автору.
4. Взять первый незакрытый шаг очереди: `[ ]` или `[~]`.
5. Коротко сообщить автору, какой шаг начат, и работать до конца шага, не задавая вопросов, если без решения автора действительно можно обойтись.

**В конце шага:**
1. Проверки (п. 9 раздела 4) и второй проход.
2. Обновить этот файл: отметка в очереди, запись в журнале. При отклонениях обновить и план — разделы 3, 5, 6, 7.2.
3. `git status` и `git diff --stat`. Добавлять файлы **поимённо** (`git add <пути>`), никогда `git add -A`: правку автора в `Prompt_Expand_Subsection.md` в коммит не включать, пока её не включат в финальном шаге.
4. Коммит на английском: `docs: expand М0.1.NN <epoch in english> (A → B lessons)`. Если в шаге добавлены биографии — `…, add N biographies`. Последняя строка — `Co-Authored-By`, которую задаёт среда. В коммит входят прогрессия, изменённые файлы других подразделов, план и этот файл.
5. Для промежуточного захода — без коммита; обновить только журнал и отметку `[~]`.
6. Отчёт автору на русском, коротко:
   - что сделано (таблица новых уроков и зачем каждый);
   - что изменено во втором проходе;
   - какие ссылки обновлены;
   - результаты проверок;
   - источники ссылками;
   - какой шаг следующий.

   Каждый термин — с английским названием и пояснением. После отчёта остановиться: следующий шаг начинается в новом чате по «Продолжай дальше».

## 9. Экономия контекста

- Большие файлы читать частями: `sed -n`, `grep -n '^#### '` для оглавления папки, `awk` по нужному уроку.
- Не перечитывать файл после правки: Edit или Write сообщат об ошибке, если она есть.
- Папку эпохи удобнее переписать целиком (Write) после того, как всё собрано: примечания меняются во всех уроках. Перед записью убедиться, что прежние пункты перенесены — это проверяет скрипт.
- Нумерацию, перенумерацию ссылок и проверки делать скриптами в scratchpad, а не вручную.
- Веб-поиски и запросы к API Commons — пакетами, параллельно.
- Если чат заканчивается раньше шага — записать промежуточное состояние в журнал (п. 5 «В конце шага») до того, как контекст кончится.
