## 2. Что меняется во всех уроках

Новые уроки — меньшая часть работы. Большая часть — 446 прежних уроков и 161 биография: сейчас у них одинаковые примечания из одной-двух строк («Цель: историческая справка о …») и одинаковые секции («Суть темы», «Ключевые события и примеры», «Связь с вычислениями»). Ни в одном уроке М0.1 нет полей «Проверенные факты», «Иллюстрации», «Термины» и «Практика».

### 2.1. Примечания

Каждый урок получает полное примечание по образцу М0.4: **Цель** (перечнем тем), **Опора**, **Акценты** (что подчеркнуть, конкретные примеры), **Граница**, **Вперёд**, **Практика**, **Для генерации** (если есть особенности), **Иллюстрации**, **Термины**, **Проверенные факты**. Папка эпохи получает примечание уровня подраздела: **Структура** (группы уроков по номерам), **Сквозная линия эпохи**, **Исправлено относительно прежней версии** (таблица «прежний номер → новый»).

### 2.3. Практика в историческом подразделе

М0.1 идёт первым, Go читатель ещё не знает — упражнения решаются на бумаге или на любом знакомом языке. Типы упражнений:

1. **Вычисление методом эпохи** — с ответом в примечании, проверенным перед записью: египетское умножение удвоением, шестидесятеричная запись, алгоритм Евклида, палочки Непера, метод конечных разностей (таблица, которую считала разностная машина), кодирование перфокарты Холлерита, код Бодо, XOR шифра Вернама, релейная схема по булевой формуле.
2. **Работа с источником** — отличить факт, реконструкцию и миф по приведённым формулировкам (Антикитерский механизм, «первый баг», «изобретатель компьютера»).
3. **Хронология и сравнение** — расставить события и машины по времени, заполнить сравнительную таблицу.
4. **Связь с эмулятором** — что пришлось бы моделировать, чтобы воспроизвести устройство: состояние, такт, ввод и вывод (для справок о машинах из модулей М1–М18).

Отдельные уроки-практикумы в конце папок не добавляются: шаблон папки эпохи их не предусматривает, а у каждого урока будет своя «Практика». Если нужен практикум — см. открытый вопрос 4.

### 2.4. Иллюстрации

М0.1 — самый иллюстрированный подраздел курса: артефакты, машины, документы, портреты. Правило — у каждого урока есть поле «Иллюстрации»; у справки — фото системы, у биографии — портрет, у темы — документ, место или прибор.

- **Источники:** Wikimedia Commons (основной); музейные собрания с открытыми лицензиями — Metropolitan Museum и Smithsonian (CC0); фотографии U.S. Army, NASA и других ведомств США (PD); консоли — фото Evan-Amos (PD); кристаллы — ZeptoBars (CC BY 3.0), John McMaster (CC BY 4.0).
- **Не брать:** Science Museum Group (CC BY-NC-SA), снимки Computer History Museum без свободной лицензии, Visual6502 (лицензия не указана), кадры игр, сканы рекламы и коробок.
- **Одно изображение — один файл:** портреты хранятся в `media/` урока-биографии в М0.1.25 и встраиваются в «Люди эпохи» и другие уроки; фото машин — в справке.
- **Объём:** около 800 уроков × 1–2 изображения × 100–150 КБ ≈ 0,1–0,25 ГБ — в пределах бюджета `budget_mb = 700`.
- Автор и лицензия каждого названного файла проверяются через API Commons при расширении папки.

### 2.5. Термины

У тем и справок появляются термины эпохи: шестидесятеричная система (sexagesimal), аликвотная дробь (unit fraction), спуск (escapement), перенос (carry), хранимая программа (stored program), линия задержки (delay line), второй источник (second sourcing), переключение банков (bank switching), эмуляция (emulation) и др. — по правилу «Термины и оригинальные названия». Для советских машин оригинал — русский, с устоявшимся английским вариантом (БЭСМ — BESM). Для имён — оригинальное написание в биографии.

## 8. Порядок работы

Одна папка — один заход и один коммит (`docs: expand М0.1.NN <epoch> (A → B lessons)`). Порядок:

1. **`00_О_подразделе.md` + папка 01** — сначала общее примечание М0.1 (сквозные линии, типы уроков, правила практики, иллюстраций и источников из разделов 2–3), затем папка 01 как образец для остальных. После этого захода стоит посмотреть результат и при необходимости поправить образец.
2. **Папки 02–24 по порядку.** Каждая — с новыми биографиями своей эпохи (вставка в М0.1.25 с полным примечанием) и с обновлением ссылок из раздела 7. Самые большие папки — 13, 18, 23 (42–48 уроков, из них 23–31 справка о машинах с проверкой фактов) — могут потребовать двух заходов: сначала темы и первая половина справок, затем вторая половина; коммит один.
3. **Папка 25** — расширение прежних биографий в четыре приёма (раздел 6.2).
4. **Финал** — `М0.16`, «Канонические источники», согласование номеров в сквозных линиях, итоговая проверка скриптом по всему М0.1.

В каждом заходе — порядок из промпта: инвентаризация, структура, примечания, проверка фактов и лицензий изображений через веб и API Commons, сквозные правки, проверочный скрипт, второй проход, коммит, отчёт.
